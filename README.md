**Единый пульт мониторинга аппаратных ключей защиты 1С:Предприятие**, подключённых через сетевые USB-концентраторы **Digi AnywhereUSB**, и серверов лицензирования **1С:СЛК**, **Guardant** и **Sentinel**.

> *A unified web console that maps hardware license dongles plugged into Digi AnywhereUSB hubs to the 1C:Enterprise, SLK, Guardant and Sentinel license servers that use them.*

---

## Зачем

В крупной инфраструктуре 1С аппаратные ключи (HASP, СЛК, Guardant, Sentinel) вставлены в сетевые USB-концентраторы и проброшены по сети на разные серверы. Чтобы ответить на простой вопрос *«в каком порту стоит ключ на 100 мест и какой сервер его сейчас держит?»*, приходится обходить веб-интерфейсы каждого концентратора, отдельно смотреть мониторы СЛК, Guardant и Sentinel и вручную сопоставлять IP-адреса с именами хостов.

**OneSLicenseHub** собирает всё это в одну страницу:

- какой ключ стоит в каком физическом порту какого концентратора;
- модель и производитель ключа (AKS HASP HL, Sentinel HL, Guardant Stealth, ключ СЛК);
- к какому серверу подключён порт — имя хоста и IP;
- какая лицензия опознана, на сколько мест и сколько из них занято;
- сводка по всем лицензиям, найденным на серверах лицензирования.

Агенты на целевые серверы ставить не нужно — сервис только опрашивает оборудование и службы по сети.

## Как это работает

```
          ┌──────────────────────────────────────────────┐
          │      OneSLicenseHub (.NET 10, Kestrel)       │
          │  фоновый опрос по расписанию + REST API + UI │
          └──────────────────────┬───────────────────────┘
          ┌──────────────────────┼───────────────────────┐
          ▼                      ▼                       ▼
 ┌──────────────────┐  ┌──────────────────────┐  ┌──────────────────┐
 │ Digi AnywhereUSB │  │ Серверы лицензий     │  │ Корреляция       │
 │ 24 Plus (HTTPS)  │  │ 1С:СЛК 3.0   :9099   │  │ порт ↔ хост ↔    │
 │ /14     (HTTP)   │  │ Guardant     :3185   │  │ лицензия         │
 │ порты, хосты, IP │  │ Sentinel ACC :1947   │  │ + DNS, KnownHosts│
 └──────────────────┘  └──────────────────────┘  └──────────────────┘
```

Опрос идёт в три этапа, всё параллельно и асинхронно:

1. **Концентраторы Digi.** AnywhereUSB 24 Plus опрашивается по HTTPS: статус каждого порта, USB-дескрипторы (производитель, модель), группы и подключённые клиенты. AnywhereUSB/14 опрашивается через встроенный веб-интерфейс: таблица RealPort и активные сетевые соединения. Там же собираются MAC, серийный номер, Device ID и версия прошивки.
2. **Серверы лицензирования.**
   - **1С:СЛК 3.0** — серии программ, серийные и регистрационные номера, число лицензий, активные процессы.
   - **Guardant (GLDS)** — аппаратные ID ключей, общий ресурс лицензий (занято/всего), клиенты.
   - **Sentinel Admin Control Center** — ключи и фичи лицензирования.
3. **Корреляция.** Порты концентраторов сопоставляются с данными серверов лицензирования по имени хоста, IP и характеристикам ключа. Если имени хоста нет, оно восстанавливается по карте `KnownHosts`, по списку процессов с серверов лицензий или через DNS. Для порта можно задать лицензию вручную через `PortOverrides`.

Последнее удачное состояние хранится в кэше: если концентратор перезагружается или ненадолго пропала сеть, данные на панели не пропадают до следующего успешного опроса.

## Возможности

- **Плотный тёмный интерфейс**: две таблицы портов (по одной на концентратор) и каталог найденных лицензий.
- **Перекрёстная подсветка**: при наведении на ключ, сервер, группу или лицензию подсвечиваются все связанные строки во всех таблицах.
- **Карточка устройства**: кнопка **«ОБ УСТРОЙСТВЕ»** в шапке концентратора открывает IP (со ссылкой на веб-консоль), MAC, Device ID, серийный номер / Product ID, прошивку и время последнего опроса, у каждого значения есть кнопка копирования. MAC и прошивка всегда видны в подзаголовке.
- **Автопоиск серверов лицензирования**: на каждом опросе сервис проверяет хосты из `InfrastructureHosts` на порты 1С:СЛК (9099), Guardant (3185) и Sentinel (1947) и добавляет найденные службы к заданным в конфигурации. Дубли отсекаются по IP.
- **Сводный реестр лицензий**: одна сплошная таблица без группировок. Колонки по порядку: где подключён или активирован ключ (порт Digi или сервер), носитель (программный или аппаратный), число лицензий, лицензия, куда проброшен ключ или какие серверы 1С его используют, ключ и серия, рег. номер, организация. Строки отсортированы по месту: порты Digi 01, Digi 02, затем серверы лицензирования. Есть фильтры по среде (DEV/PROD) и по носителю, истёкшие лицензии показаны со статусом.
- **Носитель** определяется по данным СЛК (`virtual` — программный ключ), типу лицензии Sentinel (`HASP-SL` — программная) и физическому порту Digi (аппаратный ключ).
- **Подсветка при наведении**: порты, серверы и клиенты подсвечиваются во всей таблице, как и совпадающие значения в остальных колонках.
- **Расположение лицензий**: для каждой лицензии показан порт Digi, где стоит ключ, или сервер лицензирования в виде `имя (IP)`. Имя берётся из `KnownHosts` или обратного DNS.
- **Устойчивый опрос**: до 3 попыток на концентратор; если он не ответил, показываются последние известные данные (статус `DEGRADED`), а повторный опрос идёт через 2 минуты, а не через полный интервал.
- **Опрос по расписанию**: интервал меняется прямо из интерфейса или через API (1–1440 минут), есть принудительное обновление.
- **Без внешних зависимостей на фронтенде**: чистые HTML, CSS и JavaScript, без npm и сборщиков.
- **Два режима запуска**: как консольное приложение или как служба Windows.

## Требования

- Windows 10/11 или Windows Server 2016+ (проект собирается под `net10.0-windows`, так как использует службы Windows).
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) для сборки.
- Сетевой доступ с машины, где запущен сервис, до веб-интерфейсов концентраторов Digi и до портов серверов лицензирования (`9099`, `3185`, `1947`).

## Быстрый старт

```powershell
git clone https://github.com/DarkSailas/OneSLicenseHub.git
cd OneSLicenseHub

# 1. Укажите адреса своего оборудования и учётные данные Digi
notepad src\OneSLicenseHub.Web\appsettings.json

# 2. Запустите
dotnet run --project src\OneSLicenseHub.Web
```

Откройте в браузере **http://localhost:5075**.

### Сборка релиза

```powershell
.\build.ps1
```

Скрипт собирает решение в Release, прогоняет xUnit-тесты и публикует готовый пакет в `publish\Web\`.

### Установка службой Windows

В PowerShell от имени администратора:

```powershell
cd publish\Web
powershell -ExecutionPolicy Bypass -File .\INSTALL_SERVICE.ps1 -Start      # установить и запустить
powershell -ExecutionPolicy Bypass -File .\INSTALL_SERVICE.ps1 -Uninstall  # остановить и удалить
```

## Настройка

Вся топология задаётся в секции `HubOptions` файла `src/OneSLicenseHub.Web/appsettings.json`. В репозитории лежит пример с адресами `192.168.1.x` и паролями-заглушками; образец также есть в `appsettings.example.json`.

```jsonc
{
  "HubOptions": {
    "PollingIntervalMinutes": 60,        // интервал фонового опроса
    "RequestTimeoutSeconds": 15,         // таймаут одного HTTP-запроса
    "Digi1": {                           // AnywhereUSB 24 Plus
      "Id": "digi-150",
      "Name": "Digi AnywhereUSB 24 Plus",
      "Host": "192.168.1.150",
      "Port": 443,
      "UseHttps": true,
      "Username": "admin",
      "Password": "YOUR_DIGI24_PASSWORD"
    },
    "Digi2": {                           // AnywhereUSB/14
      "Id": "digi-151",
      "Name": "Digi AnywhereUSB/14",
      "Host": "192.168.1.151",
      "Port": 80,
      "UseHttps": false,
      "Username": "root",
      "Password": "YOUR_DIGI14_PASSWORD"
    },
    "SlkServers":      [ "192.168.1.20:9099" ],
    "GuardantServers": [ "192.168.1.30:3185" ],
    "SentinelServers": [ "192.168.1.40:1947" ],
    "DefaultEnvironment": "PROD",        // среда для серверов, которых нет в InfrastructureHosts
    "DiscoveryTimeoutMilliseconds": 1500,
    "InfrastructureHosts": [             // где искать серверы лицензирования
      { "Host": "app-dev-01",    "Environment": "DEV" },
      { "Host": "app-server-01", "Environment": "PROD" }
    ],
    "KnownHosts": {                      // IP → имя хоста, если нет DNS
      "192.168.1.50": "app-dev-01"
    },
    "PortOverrides": {                   // ручное назначение лицензии порту
      "digi-150:1": {
        "ProductName": "1С:Предприятие 8 (Клиентская лицензия 300 мест)",
        "Category": "1C:Платформа HASP",
        "LicenseType": "Сетевой ключ HASP Net",
        "TotalCapacity": 300
      }
    }
  }
}
```

> **Не коммитьте реальные адреса и пароли.** Держите боевые значения в `appsettings.Production.json` (загружается поверх `appsettings.json` и уже внесён в `.gitignore`) или в переменных окружения, например `HubOptions__Digi1__Password=...`.

### Правила сопоставления

Логика опознавания ключей находится в `LicenseHubAggregator.CorrelatePortsWithLicenses`. Кроме общих правил (по производителю и модели ключа, по имени хоста), в ней есть привязки к конкретным номерам портов, ID ключей Guardant и фрагментам имён хостов (`key05`, `app01` и т. п.) из исходной инсталляции. В этом репозитории они заменены на условные значения. Под свою инфраструктуру их нужно поправить или заменить на `PortOverrides`.

## REST API

| Метод | Путь | Что делает |
|:--|:--|:--|
| `GET`  | `/api/overview` | Полный снимок: концентраторы, порты, лицензии, счётчики (кэш 30 с). |
| `POST` | `/api/overview/refresh` | Принудительный опрос всего оборудования и служб. |
| `GET`  | `/api/devices/{id}` | Данные одного концентратора (`digi-150`, `digi-151`). |
| `GET`  | `/api/settings` | Интервал опроса, время последнего и следующего обновления. |
| `POST` | `/api/settings` | Смена интервала опроса: `{ "pollingIntervalMinutes": 30 }`. |
| `GET`  | `/health` | Проверка работоспособности. |

Ответ `/api/overview` содержит также `licenseServers`: список серверов лицензирования с источником (`config` или `discovery`), средой, состоянием (`Ok`, `Empty`, `Unreachable`) и числом лицензий.

Вкладки интерфейса открываются по адресу: `/#catalog`, `/#both`, `/#digi-150`, `/#digi-151`.

В режиме `Development` доступен Swagger UI по адресу `/swagger`.

## Безопасность

- Сервис слушает `http://*:5075` **без аутентификации**. На панели видны внутренние IP, имена серверов и состав лицензий, поэтому ограничьте доступ к порту брандмауэром или поставьте перед сервисом обратный прокси с авторизацией.
- Учётные данные концентраторов Digi хранятся в конфигурации открытым текстом. Выдавайте учётной записи минимальные права и ограничьте доступ к файлу конфигурации на сервере.
- Для AnywhereUSB 24 Plus проверка TLS-сертификата **отключена полностью**, потому что у устройств самоподписанные сертификаты. Опрашивайте концентраторы только внутри доверенного сегмента сети.
